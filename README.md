# Urban Mobility Optimisation

This repository contains the preliminary Python implementations developed during the early stages of my doctoral research in urban mobility modelling and optimisation.

## Purpose

The code was developed to build computational understanding of graph theory, routing algorithms and optimisation techniques before the main research implementation.

The repository currently includes notebooks covering:

- Transport network representation
- Graph theory fundamentals
- Dijkstra's algorithm
- A* algorithm
- Bellman–Ford algorithm

These notebooks represent technical preparation and learning rather than research findings. The repository will continue to evolve throughout the research programme.

## Software

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
